Remaining

The rest of the backend: teachers, students, classes, attendance, exams and results.

02 · How a school joins
Principal signs up

Logs in and opens “Create school”.

Sends a request

School details are saved in the backend as “pending”.

Super admin approves

The app owner reviews the request in the admin panel.

School goes live

Only now can the school be used and its people added.

03 · Problems I hit, and how I solved them
ProblemAnyone could create a fake school

With open signup, anyone can call themselves a principal and fill the system with junk schools.

SolutionRequest first, then admin approval

A new school stays “pending” until the super admin approves it. Unapproved schools can’t be used.

ProblemFake teachers and students joining

If anyone can join with a school code, outsiders can get into a class.

Solution · building nextJoin only if the school added you

The school adds its teachers and students first. A join only works if it matches one of those records.

ProblemTwo backends for one app

Firebase and the Express API both held app data, so there were two places to keep in sync and secure.

SolutionRemoved Firebase completely

Auth and all school data now live in one Express + MongoDB backend.
